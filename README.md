
# Amazon-Style Retail Services Web Application
Educational Amazon-style retail web application developed using:
  Linux services, Docker, Flask, virtual machines, internal networking, and HTTP service communication.

## Services
- Frontend Service (Port 8000) - serves the web pages and communicates with backend services.
- Catalog Service (Port 5001) - provides available products  and runs in a Docker container.
- Login Service (Port 5002) - validates user login credentials (mobile number/email and password).
- Cart Service (Port 5003) - manages cart contents, quantities, and total cost calculations.
